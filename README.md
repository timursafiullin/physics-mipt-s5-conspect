# Квантовая физика (МФТИ, ПИШ ФАЛТ, ИВТ, V семестр) — ответы на экзаменационные вопросы

**ВАЖНО! Всё, что есть в репозитории, в том числе и сам конспект – сгенерировано Claude Opus 5.5 (High). Возможны ошибки и неточности.**

Готовый документ: `Quantum_Physics_Exam_Notes.pdf` (A4, ~140 страниц, интерактивное оглавление и закладки).

## Структура проекта

```text
.
├── main.tex              — главный файл: титульный лист, оглавление, подключение билетов
├── preamble.tex          — оформление: шрифты, цветные блоки, колонтитулы, макросы обозначений
├── .latexmkrc            — настройки сборки (XeLaTeX, вывод в build/)
├── chapters/
│   ├── notation.tex      — обозначения, система единиц, физические постоянные
│   ├── ticket_01.tex … ticket_20.tex — по одному файлу на билет
├── fonts/                — шрифты CMU Serif / Sans / Typewriter (лицензия OFL, см. CMU-README.md)
└── build/                — сюда latexmk складывает промежуточные файлы и PDF
```

Все рисунки и графики построены в TikZ/PGFPlots прямо в файлах билетов (отдельная папка `figures/` не нужна).

## Сборка

Требуется TeX Live 2023+ или MiKTeX с XeLaTeX и пакетами `fontspec`, `unicode-math`, `polyglossia`
(с русскими переносами), `tcolorbox`, `pgfplots`, `titlesec`, `fancyhdr`, `hyperref`. Шрифт формул —
Latin Modern Math (входит в дистрибутивы); текстовые шрифты лежат в `fonts/`, устанавливать их не нужно.

Из корня проекта:

```bash
latexmk            # результат: build/Quantum_Physics_Exam_Notes.pdf
```

Без `latexmk` (например, MiKTeX без Perl) — дважды, чтобы обновились оглавление и ссылки:

```bash
xelatex -output-directory=build -jobname=Quantum_Physics_Exam_Notes main.tex
xelatex -output-directory=build -jobname=Quantum_Physics_Exam_Notes main.tex
```

Компилировать нужно из корня проекта: пути к шрифтам (`fonts/`) относительные.

## Соглашения

- Гауссова система единиц (СГС); правила перехода к СИ — в разделе «Обозначения».
- Каждый билет: формулировка → определения → основная теория → выводы (пронумерованные блоки
  «Вывод N.k») → итоговые формулы → физическая интерпретация → «Что необходимо знать на экзамене».
- Указания программы «без вывода» соблюдены: результат сформулирован и объяснён, вывод не требуется
  (в билетах 8, 9, 10 приведены лишь проверки подстановкой).
